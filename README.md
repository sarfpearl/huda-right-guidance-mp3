# Huda Bayan 🕌🎧

An immersive, state-of-the-art Islamic Audio & Bayan web application built with **Next.js 15 (App Router)**, **TypeScript**, and **Vanilla Tailwind CSS**. Inspired by `https://tamilfm.co/v/auto`.

---

## ✨ Features

- 🎨 **Neomorphic 3D Audio Player**: Dark glass player card with animated equalizer, progress slider, and transport controls.
- 📺 **YouTube Music & Playlist Integration**: Connect and stream YouTube Music playlists (e.g. Ramadan `PLFRt54vRoHJs`).
- 🕌 **16 Atmospheric Islamic Categories**: High-definition scene backgrounds for *Iman & Taqwa*, *Qur'an*, *Salah*, *Dua*, *Ramadan*, *Hajj & Umrah*, etc.
- 🎛️ **Mac-Style Right Control Center**: Slide-out drawer with 3 tabs (*Categories*, *Speakers*, *Explore*) and instant live search.
- 📱 **Mobile & Desktop Responsive**: Fully optimized touch targets, safe-area padding, and keyboard navigation.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run TypeScript check
npm run typecheck

# Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to launch the app.
